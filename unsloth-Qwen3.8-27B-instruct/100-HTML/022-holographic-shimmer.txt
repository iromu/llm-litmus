Holographic Shimmer — Premium Card
===================================

Creative Prompt
---------------
Create a holographic premium card with an iridescent shimmer effect. The card has a conic-gradient animated border that spins continuously, a multi-color shimmer background, and a moving light overlay. The content includes a badge, gradient title, description, pricing, feature list with checks, and a gradient CTA button. The card tilts in 3D on mouse move, responding to cursor position with perspective transforms. The conic gradient border angle also follows the cursor. The aesthetic is futuristic, premium, and iridescent — like a holographic credit card or limited edition collectible.

Model: Qwen3.8-27B-instruct
Thinking effort: high

Techniques Used
---------------
- CSS @property custom property (--border-angle) to animate a conic-gradient border; angle is driven by keyframes when idle and overridden by JS to follow the cursor on hover
- Multi-layer iridescent shimmer: linear-gradient background-size sweep, diagonal light-band overlay (mix-blend-mode: screen), and a repeating-linear-gradient "hologram film" interference layer
- 3D perspective tilt via JS pointer tracking (rotateX/rotateY + translateZ + scale), with smooth transition back on pointer leave
- Cursor-following specular highlight (radial-gradient positioned by --mx/--my custom properties)
- Gradient text clipping (-webkit-background-clip: text) for the title and price, with animated background-position shift
- Glassmorphism content styling (backdrop-filter blur, translucent borders, inset highlights)
- Floating idle animation (gentle rotateX/rotateY/translateY loop) that suspends while hovered
- Ambient scene: radial-gradient aurora blobs with blur, fine grid texture overlays, rising particle field generated by JS
- Hover scale + shine sweep on the gradient CTA button
- Responsive sizing via clamp() and min(); prefers-reduced-motion support disables all animations
