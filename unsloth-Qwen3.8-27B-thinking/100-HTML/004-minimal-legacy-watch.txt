004 — Minimal Legacy Watch
================================================================

PROMPT (verbatim)
----------------------------------------------------------------
Create a luxury watch product showcase with a vintage editorial aesthetic. A realistic 3D CSS watch face shows an animated working clock with hour, minute, and second hands. The watch has a rose gold body with a cream dial, Roman-style markers (generated by JavaScript), a date window, crown, and leather strap. The layout is a two-column split: the watch on the left with subtle 3D perspective and floating animation, and editorial content on the right including tag, headline, italic description, specification grid, and a call-to-action button. The color palette is warm neutrals, cream, rose gold, and dark brown. Serif typography throughout.

MODEL
----------------------------------------------------------------
Qwen3.8-27B (thinking) — thinking effort: high

TECHNIQUES
----------------------------------------------------------------
CSS 3D transforms with preserve-3d and perspective, animated floating keyframes, radial gradients for metallic sheen, JavaScript-generated watch markers, real-time clock with setInterval, responsive grid layout, hover interaction on button with color inversion, multi-layered box-shadow for realistic depth.

INTERACTION MODEL
----------------------------------------------------------------
Watch face shows live time updating every second. The watch body responds to hover with subtle 3D rotation change. Button has hover color swap. Page is responsive, stacking vertically on mobile.

IMPLEMENTATION NOTES
----------------------------------------------------------------
- Single self-contained HTML file; all CSS/JS inline; system serif stack
  (Georgia / 'Times New Roman' / 'Palatino Linotype'); no CDNs, fonts,
  images, or frameworks. Paper-grain texture is an inline SVG data-URI.
- 60 dial spokes generated in JS: Roman numerals (watchmaker's IIII) at
  hour positions + square index dots + 48 minute ticks.
- Clock uses Date() + setInterval(1000); cumulative-angle stepping so
  hands never rotate backwards across the 12:00 boundary; second hand
  ticks with slight overshoot easing; first paint skips the sweep-in
  transition.
- 3D stack: case / crown / bezel / dial / cap / glass layered with
  translateZ(2–14px) under perspective:1300px; hover eases rotation
  from rotateY(18deg) rotateX(8deg) toward near-flat.
- Date window shows the live calendar date.
- Responsive: two-column split stacks to one column below 920px;
  watch sized with clamp(220px, 40vmin, 380px); honors
  prefers-reduced-motion.
- Verified: inline script passes `node --check`; no external requests.
