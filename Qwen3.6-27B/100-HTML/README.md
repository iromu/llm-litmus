# 🎨 100 HTML — A Gallery of Digital Art

**100 completely self-contained HTML files, each a visually stunning, standalone piece of digital art.**

Every page is a unique design showcase — zero dependencies, zero external assets, zero frameworks. Just raw HTML, CSS, and JavaScript working together to create something beautiful.

## 🎯 Design Philosophy

Every page aims to be:

- **Visually impressive** — Would you bookmark it? Would it stand out in a design showcase?
- **Technically pure** — No frameworks, no CDNs, no external fonts or images. Every byte is authored.
- **Responsive** — Works on any screen size.
- **Offline** — Everything is inline. Open the file and it works.
- **Unique** — 100 different concepts, not 100 color variations of the same idea.

## 🚀 How to Use

```bash
# Clone the repo
git clone <repo-url>

# Open any file directly in your browser
open 001-aurora-glass.html
# or just double-click the file
```

No build step. No server required. No internet needed.
