# Glass Dashboard

## Creative Prompt
Create a premium analytics dashboard with a glassmorphism aesthetic. The page features blurred background orbs, glass cards with KPI metrics (revenue, users, conversion, bounce rate), a weekly bar chart, a donut chart for traffic sources with SVG circles, and a recent activity feed. The glass cards have backdrop-filter blur, subtle borders, and hover lift. The color palette uses dark purple gradient background with cyan, green, blue, yellow, and pink accents. The overall aesthetic is premium, data-driven, and crystalline — like a high-end financial dashboard.

## Techniques Used
- CSS glassmorphism (backdrop-filter blur, semi-transparent backgrounds, light borders)
- Multi-layered background orbs with float animation
- CSS grid layout for KPI cards
- Flexbox bar chart with dynamic heights and staggered animation
- SVG donut chart with stroke-dasharray animation
- Sparkline mini-charts with opacity gradients
- Responsive breakpoints for tablet and mobile
- Activity feed with colored dot indicators
- Hover lift transitions with box-shadow glow
- Tabular numeric formatting for data tables
- CSS custom properties for consistent theming
- Staggered requestAnimationFrame animations for chart rendering

## Interaction Model
Hover over KPI cards and chart cards triggers a lift effect with subtle shadow glow. Bar chart bars animate upward on load with staggered timing. Donut chart segments draw in sequentially. Sparkline bars fade in with progressive opacity. Bar tooltips appear on hover showing exact values. Background orbs drift continuously with independent float animations.
